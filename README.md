**기능 설명 및 플레이 영상**

https://youtu.be/DnXiclH4RpE

**프로젝트 개요**

- Unreal Engine 5와 Gameplay Ability System(GAS)을 기반으로 
액션 중심 게임 시스템 구현을 목표로 제작한 소드아트온라인 모작 프로젝트입니다.
- 원작 리소스를 사용하되, 캐릭터 액션과 전투 시스템은
리소스 특성에 맞춰 직접 설계했습니다.
- GAS와 데디케이티드 서버를 핵심으로 콤보 전투와 전투 연출을 개발했습니다.
  
**개발 목표**

- GAS 기반 어빌리티 구조로 콤보·스킬·궁극기 등 다양한 전투 패턴 확장 구조 구현
- 무기별 캐릭터 액션 및 실시간 무기 교체 구현
- 데디케이티드 서버 환경에서 클라이언트 예측 기반의 이동 동기화 구현
- 락온 카메라, 컷씬, 이펙트 등 전투 연출 구현
